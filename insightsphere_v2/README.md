# InsightSphere AI Pro — v2

## Setup

### Backend
```bash
cd backend
pip install -r requirements.txt
python main.py
```

Open: http://localhost:8000

### Environment (.env)
Copy `.env.example` to `.env` and fill in your Anthropic API key.

## Features
- 📊 Real-time analytics dashboard
- 🤖 Claude AI-powered insights, chat & reports
- 📈 Holt-Winters forecasting with AI narrative
- 🔴 WebSocket live data feed
- 🗺️ Engagement heatmap
- 📁 CSV upload support
